MioCodec decoder in the browser

MioCodec-25Hz-24kHz の デコーダを web-xpu-ops の op だけで 組み、ブラウザで動かします。サーバも Python もありません。

これは text-to-speech ではありません

テキストからトークンを作る MioTTS の言語モデルには ONNX export がまだ無いため （#106 の次段）、 ここで再生されるトークンは実際の音声クリップを本家の実装でエンコードしたものです。 動いているのはパイプラインの後半、コーデックのデコーダです。

初回はチェックポイントを Hugging Face から 523 MB ダウンロードします。 デコードは WebGPU が使えればカーネル、無ければ参照実装で走ります。 どちらで走ったかは結果欄に表示されます（?backend=cpu で強制可）。

この数字の読み方

web-xpu-ops には各 op の reference（正しさの定義であり、意図的に最も遅い実装）と WGSL カーネルの両方があります。WebGPU 経路が載せているのは matmul / conv1d / iSTFT の 3 つだけで、 残りの段（layernorm・rope・attention・group_norm など）は reference のままです。 データ量に対して線形なそれらより、この 3 つに演算量が集中しているためです。 つまり出る RTF はハイブリッドの値であり、 全段カーネル化した場合の数字ではありません。 ライブラリ自身も全 op について “Speed is unmeasured” と明記しています。

正しさは別途担保しています。デコーダは本家実装の各段の中間テンソルと突合してあり、 段ごとの一致は相対 2.1e-6〜2.2e-5、実音声 6 秒の波形全体では相対 1.2e-4 です。
