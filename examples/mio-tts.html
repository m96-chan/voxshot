MioTTS — text to speech in the browser

MioTTS-0.6B（Qwen3, int8）が テキストを音声トークンにし、 MioCodec のデコーダが 24 kHz の波形にします。両方とも web-xpu-ops の WGSL カーネルで、 すべてこのページの中で動きます。サーバ推論も Python もありません。

WebGPU が必須です

言語モデルは WebGPU 常駐エンジン（1 トークン = 1 submit、読み戻しは logits のみ）で 走ります。CPU フォールバックは意図的にありません（参照実装はテストのオラクル専用）。 話者は同梱フィクスチャの global embedding 固定です。

初回は LM の int8 重み（約 583 MB）と MioCodec のチェックポイント（523 MB）を ダウンロードします。2 回目以降のクリックは生成だけが走ります。
